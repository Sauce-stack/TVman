# TVman

A 3D third-person combat game with an over-the-shoulder camera, made with Godot 4.7.2 and
GDScript.

## Status

**Milestone 0 — setup.** The repository, its conventions and its CI exist. There is no game yet.
See [docs/roadmap.md](docs/roadmap.md).

## Getting started

1. Install [Godot 4.7.2 standard](https://godotengine.org/download) — not the .NET build.
2. Clone the repository with GitHub Desktop. Git LFS is bundled and runs on its own.
3. Open `project.godot` in Godot. The first open imports every asset.

The rules of the repository are in [docs/contributing.md](docs/contributing.md).
