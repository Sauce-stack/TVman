# Roadmap

## M0 — Setup ← current

Exit criteria:

- The repository exists on `Sauce-stack/TVman`, with CI green on `main`.
- `main` is protected: pull requests only, `CI gate` required.
- The project opens in Godot 4.7.2 with no errors.

## M1 — Prototype

Built from Godot primitives. Exit criteria:

- A capsule moves, the over-the-shoulder camera looks and never clips through a wall.
- One melee attack and one shot land on a dummy, on keyboard and on a pad.
- The first question of the design is answered: does the fight feel good from over the shoulder?
